## 2. ⚠️ 本机构建的三个坑（务必照做）

**坑 1：`pnpm check` / `pnpm build` 在本机是坏的**
pnpm 的 `verify-deps-before-run` 会因为 esbuild 的 build script 被忽略而直接失败。
绕过方式：直接跑 node 入口。

```powershell
node node_modules\typescript\bin\tsc
node node_modules\eslint\bin\eslint.js src
node core_modules\vite\bin\vite.js build      # 实际路径 node_modules\vite\bin\vite.js build
```

**坑 2：只用 `cargo build --release` 打包会得到"空壳 exe"**
Tauri 的前端资源是通过 tauri CLI 嵌入的。直接 cargo 编译出来的 exe 里**没有 `assets/index-*.js`**，
启动后窗口空白、岛不显示（曾经因此以为"岛消失了"）。

必须用 Tauri CLI：

```powershell
$env:TMP="D:\xijia\DSH\_tmp"; $env:TEMP="D:\xijia\DSH\_tmp"; $env:TMPDIR="D:\xijia\DSH\_tmp"
$env:RUSTUP_HOME="D:\xijia\DSH\toolchain\rustup"
$env:CARGO_HOME="D:\xijia\DSH\toolchain\cargo"
$env:RUSTUP_TOOLCHAIN="stable-x86_64-pc-windows-gnu"
$env:PATH = "D:\xijia\DSH\toolchain\cargo\bin;D:\xijia\DSH\toolchain\binutils\mingw64\bin;D:\xijia\DSH\toolchain\rustup\toolchains\stable-x86_64-pc-windows-gnu\bin;" + $env:PATH
node node_modules\@tauri-apps\cli\tauri.js build --no-bundle --config '{\"build\":{\"beforeBuildCommand\":\"\"}}'
```

- `beforeBuildCommand` 置空是绕过坑 1（先手动跑 vite build）
- `binutils` 必须在 PATH，否则 `tauri-winres` 报 `NotAttempted("windres")`
- `TEMP` 指到工作区内，否则链接器报 `Cannot create temporary file in ... Permission denied`

**坑 3：部署必须"先杀进程再覆盖"**
exe 被占用时 `Copy-Item` 会失败，且可能静默留下旧文件。做法：

```powershell
Get-Process focusd-island -ErrorAction SilentlyContinue | Stop-Process -Force
for ($i=0; $i -lt 12; $i++) { Start-Sleep -Milliseconds 700; try { Copy-Item $exe $inst -Force -ErrorAction Stop; break } catch {} }
# 校验：哈希一致 + exe 内含当前 dist 主包名
Start-Process $inst -WorkingDirectory (Split-Path $inst)
```
